# 阶段 4 报告：SOH 感知退化成本接入领导者目标

## 1. 目的

把 SOH 分组状态转化为当前小时调度可以使用的边际循环退化成本，并接入 `GameCase`、滚动控制器和现有领导者目标函数。

## 2. 完成内容

- `marginal_cycle_cost_per_kwh()`：根据当前 SOH 分组、电池数量、循环退化参数和参考 DOD 计算边际循环成本；
- `calendar_degradation_cost_per_day()`：计算日历老化成本，用于日级经济评价；
- `GameCase.effective_deg_cost_per_kwh`：有动态状态时返回 SOH 感知成本，没有动态状态时保持原线性成本；
- `equilibrium.py` 和 `baseline.py` 使用算例的有效退化成本系数；
- `RollingSFSEController` 在绑定 `BatteryState` 时自动使用 SOH 感知的循环退化成本。

## 3. 成本探针结果

单电池额定容量 7500 kWh、参考 DOD 50% 时：

| SOH | 边际循环成本（元/kWh） |
|---:|---:|
| 1.00 | 0.2652 |
| 0.95 | 0.2873 |
| 0.90 | 0.3094 |
| 0.82 | 0.3447 |
| 0.75 | 0.3757 |
| 0.70 | 0.3977 |

当前旧模型的吞吐量成本为 0.05 元/kWh，因此动态状态模型会更明确地惩罚高退化储能动作。

## 4. 建模说明与限制

现有实测退化公式对 SOH 的残值导数是常数，直接使用它不会产生明显的 SOH 分组成本差异。本阶段加入了透明的“剩余寿命磨损系数”：SOH 越低，边际循环成本越高。该系数目前是可解释的临时近似，后续需要通过长期 SOH 试验或替换事件数据校准，不能直接作为最终论文参数。

日历老化成本目前作为日级经济评价项计算；它与小时动作的关系主要通过 SOC 平均值体现，下一阶段将把日历成本、循环成本和替换成本统一纳入长期滚动收益。

## 5. 测试结果

- 退化成本测试：4/4 通过；
- 状态接入测试：3/3 通过；
- 论文测试：4/4 通过；
- 无动态状态时，当前 SFSE 基线仍使用原来的 0.05 元/kWh；
- 动态状态时，低 SOH 的边际退化成本高于高 SOH。
