# 主论文实验计划

## A. 数据实验

1. 高速服务区正常充电会话清洗；
2. 跨小时充电电量分摊；
3. 站点/小时基础 EV 负荷；
4. 用户群参数；
5. 价格分箱和观测响应；
6. 按日期留出测试，避免随机交易拆分泄漏。

## B. 算法对比

| 方法 | 动态 SOC | 用户响应 | DC 网络约束 | 作用 |
|---|---:|---:|---:|---|
| 固定电价+规则储能 | 否/简单 | 否 | 否/后验 | 工程基线 |
| 单层经济优化 | 是 | 聚合 | 是 | 优化基线 |
| 无动态 SOC 博弈 | 否 | 是 | 是 | 消融 |
| 无备用博弈 | SOC但无备用 | 是 | 是 | 消融 |
| 本文动态 SFSE | 是 | 是 | 是 | 主方法 |

## C. 场景

- 正常供能；
- 风光低出力；
- EV 高到达负荷；
- PV/Wind 过剩；
- 初始 SOC 20%、50%、80%；
- 预测误差 ±5%、±10%、±20%；
- 不同用户价格敏感性。

## D. 指标

- 运营商净利润；
- 用户充电成本；
- EV 服务满足率；
- EV 失负荷量；
- PV/Wind 弃电量；
- 最低 SOC 和备用裕度；
- 节点电压和线路电流；
- 电池 SOH 日衰减；
- 计算时间和收敛率。
