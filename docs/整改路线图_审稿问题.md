# 审稿问题整改路线图

## 目标

将论文和实现从“可行性演示”推进到可审计的项目级实验：明确 SOH 的真实作用边界，建立动态/固定价格的公平比较，确认网络与热约束是否进入定价闭环，并重构与项目需求一致的 Agent 基准。

## 优先级与依赖

### P0：先修正结论边界和评价口径

- 明确低、中、高需求日的 SOH 结果只能支持“场景依赖的影响”，不能支持普遍服务提升。
- 动态与固定价格必须同时报告请求量、共同请求下的服务量、绝对服务量、用户成本、运营商收益和弃电/电池损耗。
- 删除或收窄“动态定价优于固定定价”“提升可再生能源利用率”“达到 Stackelberg 均衡/全局最优”等未经证明的表述。
- 将当前 Agent 结果限定为“特定信息条件、动作空间和奖励下的诊断结果”。

### P1：模型闭环审计

- 核实 DC 潮流、电压、电流、热约束是否进入领导者价格候选评价，而不是仅在调度后验检查。
- 核实 SOH 容量反馈与退化成本反馈是否被独立消融。
- 统一规划和执行的 SOC/备用约束，并统计规划动作被执行层修改的比例。
- 给出价格、需求、SOH、预测价格四类残差及归一化停止准则，单独标记未收敛步。

### P1：公平实验设计

- 增加共同需求回放：固定用户请求，仅比较储能/网络调度。
- 增加完整季节或多日期 SOH 扫描，而非只依赖三个代表日。
- 增加价格网格、初始 SOH、初始 SOC、预测误差和低可再生出力敏感性。

### P2：Agent 重构

- 先确定 Agent 的职责：价格策略、储能功率控制，或两者分层协同；禁止用不同职责的 Agent 与 MILP 做不公平比较。
- 状态至少覆盖滚动窗口内的可再生预测、负荷/请求、SOC、SOH、备用裕度、网络瓶颈/电压电流摘要、上一动作和时间信息。
- 动作与优化基准保持同一决策边界；若 Agent 输出价格，则必须与同一价格网格和需求响应接口比较；若输出储能功率，则 MILP 也应在同一已知/预测信息条件下比较。
- 奖励使用执行服务量、未服务惩罚、网络违约惩罚、弃电与电池转换损耗、退化成本和动作平滑项，避免单独奖励耗散式减少弃电。
- 采用安全投影或可行性层，并报告投影率、约束违约率、服务失败率和跨种子置信区间。

## 分支任务

1. `experiment_claims`：实验与论文结论审计，输出必须补做的实验和应删除/收窄的表述。
2. `network_loop`：网络/热约束闭环审计，输出最小实现路径和验收实验。
3. `agent_redesign`：Agent 状态、动作、奖励、训练和公平基准设计；优先基于现有 `src/game/rl.py` 与 `src/game/env.py`。

## 主线程协调规则

- 先收集三条分支的只读审计，再决定实现顺序。
- P0 结论边界先于 P1/P2 代码实现；否则容易把未验证结果重新包装成强结论。
- 网络闭环和公平需求基准是 Agent 验收的前置条件。
- Agent 改动必须通过统一信息集、动作空间和奖励口径的对照实验后，才能进入论文主结果。

## 验收证据

- 一份实验矩阵，列出方法、信息集、动作空间、约束、奖励/目标和指标。
- 一份网络闭环证据，证明价格候选评价调用了网络/热约束，而非仅后验检查。
- 一份 SOH 四路消融和多场景统计结果。
- 一份公平 Agent 对照结果，包含 MILP、规则基线、当前 Agent、重构 Agent，及可行率、服务量、损耗、退化和计算时间。
- 更新论文摘要、结果、讨论和结论，使强结论与证据范围一致。

## 审计结论与禁止性边界

### 实验与论文口径（`experiment_claims`）

- 30 日动态价格请求/服务为 61.72/58.57 MWh，固定价格为 114.37/67.13 MWh；动态服务率较高主要来自压低请求，且动态弃电 20.16 MWh 高于固定价格的 11.27 MWh。动态结果含 4 个外循环未收敛步，因此只能作为 bounded-iteration 描述性结果。
- SOH 代表日结果是在 SOH=1、独立单日起点下取得；低 SOH=0.80 的高需求压力测试未收敛。不得写成低、中、高 SOH 下已证明寿命或服务收益。
- 当前每次外迭代只做一次离散价格坐标扫描，混合单位 residual 取最大值，且未把 forecast-price fixed point 纳入停止证书。不得声称 Stackelberg 均衡或全局最优。
- 弃电惩罚实验已显示 curtailment 减少几乎一比一转为 battery losses；利用率结论必须同时报告 useful service、battery loss、curtailment+loss、throughput 和 terminal SOC。
- `scripts/run_dynamic_dc.py` 与 `scripts/run_24h_dc_experiment.py` 存在 EV 容量、固定电价、时间步长和风光输入口径漂移，统一实验契约前不得做公平性能比较。

### 网络闭环（`network_loop`）

- `equilibrium.py` 和 BRI 价格候选评价没有内生 DC 电压、电流、热约束或 I2R 网损；网络主要在执行层后验计算损耗。
- 默认支路 `current_limit_a=0`，热约束没有额定数据，`thermal_limits_verified=False`。在补齐约束并接入候选评价前，禁止使用“网络/热约束已验证”“安全约束已满足”等表述。
- 最小低风险闭环是先将潮流评价接入 BRI/滚动控制的每个价格候选，记录 voltage/current/thermal margins；MILP 内生网络约束需单独作为后续扩展，不得用后验检查冒充均衡内生约束。

### Agent 契约（`agent_redesign`）

- 当前 `PricingEnv` 是单步 contextual bandit，观测缺少 SOC、SOH、reserve、backlog、上一价格、时间、网络限制和不确定性。
- 旧 `PolicyNet/train_policy` 仍保留连续高斯动作作为兼容入口；新增 `DiscretePolicyNet` 使用价格档位，但尚未接入训练循环。新主线必须使用离散策略。
- Agent reward 已按安全投影后的执行服务量结算，并统一退化/失负荷/弃电的 `interval_hours`；还需将首槽 `RewardBreakdown` 接入时序环境并核验 DC 执行层成本。
- `safety.py` 与滚动首槽 kWh→kW 已按 `interval_hours` 修复并有回归测试。
- follower 使用弹性需求上限，而 equilibrium 使用固定上下限；两者不是同一个问题。必须统一需求响应模型后再训练或比较 Agent。

### Agent 动作语义决策

- 已确定 Agent 动作是当前滚动窗口的 `T` 维离散价格计划（`MultiDiscrete([K] * T)`），每个环境 step 只执行首槽；这与现有滚动控制器的规划/执行边界一致。
- MDP 环境必须先复用统一的 `step_with_prices/execute_plan` 执行入口，再实现 `reset/step` 状态转移；禁止让 Agent 直接调用与 MILP 不同的 follower、安全层或 DC 路径。
- 状态最低包含窗口预测、SOC、SOH、可用容量、备用裕度、当前/积压 EV、上一实际价格、时段索引和网络约束摘要；每步 reward 使用首槽 `RewardBreakdown`。

### 公平实验执行契约

- 新 runner 需冻结同一 48×0.5 h 的 PV/Wind/non-EV/EV request trace、日期、SOC/SOH、积压、终端 SOC、EV 上限和输入 manifest/hash；固定价格与动态策略只改变调度/价格，common replay 中不得重新生成请求。
- endogenous demand 另设独立模式，报告 requested 与 suppressed demand，不能把服务率直接用于政策排名。
- 每条 step 记录 request/served/shed kW、price、storage、弃电、网络损耗、SOC/SOH 和各类残差；summary 按 `dt` 积分并报告绝对服务量、服务率、battery conversion loss、curtailment+loss、端状态、收益和运行时间。
- 运行脚本当前存在 48×0.5 h 动态与 24×1 h 固定、EV cap 480/960、动态收入漏乘 `dt` 等口径冲突；这些冲突修复前，旧汇总只能作诊断，不能作公平比较。
- `balance_dc_step` 的 `residual_kw` 是功率量，验收时必须按 `dt` 积分并单列 `unserved_rigid_kw`；不得把瞬时残差直接当作 kWh 能量守恒证据。
- common trace 还要拆分物理 request、price-responsive accepted demand、刚性 EV 负荷和 backlog；不能直接把动态策略生成的 endogenous request 当成公平回放输入。
- SOH 实验矩阵为 `{1.0,0.9,0.8,0.7} × {P10,P50,P90} × 至少3个日期/种子`，并分离容量反馈、成本反馈；每格报告 `n/converged/n_nonconverged`，未收敛样本不进入性能均值。
